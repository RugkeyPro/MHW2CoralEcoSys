# Scientific analysis modules

`conservation_demo` supplies the self-contained, real-input calculation behind the repository-root `MHW2CoralEcoSys_demo.ipynb`. It includes all 29,746 archived numeric reef-cell inputs, original member support masks, seven unchanged scientific functions and complete frozen comparison records. The Notebook is the primary interactive entry and displays each newly calculated stage.

Other full-project scripts are retained in `research_workflow/` with their upstream input requirements. They do not use the small demo as a substitute for unavailable full model inputs. The older result-table/browser demonstration is archived, rather than presented as a new scientific pipeline.
